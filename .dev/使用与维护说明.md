# 个人工作台

本地 Obsidian 个人工作台，由 Decisions（方向）、Daily（执行）、Manual（效率）三个平级板块组成。旧笔记保留原来的内容和写法，日记与计划按需要使用模板。总体目标单列。

## 开始使用

1. 在 Obsidian 中选择“打开文件夹作为仓库”，选择当前日记文件夹。
2. 启用已附带的社区插件，打开根目录 `MOC.md` 主页，启动时以阅读模式打开这里。
3. 从三个入口选择所需板块。Daily 中点击“今天”或使用日历，自动补齐关联的年、季、月、周计划和日记。Decisions 和 Manual 是普通目录，在其中自行新建笔记即可。

快捷键：Alt+D 打开今天，Alt+W 打开本周。首次创建后等待约一秒即可自动套用模板。

命令面板提供“打开首页”以及打开今天、本周、本月、本季、今年计划的命令。

## 三个板块的分工

| 板块 | 功能与交付 | 使用方式 |
| --- | --- | --- |
| `02. Decisions` | 保存实际问题、重要选择及思考过程 | 自行写笔记和组织子目录。 |
| `01. Daily` | 安排生活、记录经历、推进事情；留下具体行动、真实记录与接续安排 | 沿用年、季、月、周、日目录，承接决策，需要时引用方法。也保留感受与自由写作。 |
| `03. Manual` | 积累实践中形成的技能、方法与经验 | 自行写笔记和组织子目录。 |

三个板块分别有 README 入口，独立使用、按需链接。Decisions 和 Manual 仅保留简短目录说明，内容、模板和组织方式由自己在实践中形成。Daily 保留现有日记与计划功能。

已整理两处旧库中的日记和计划，记录日期为 2025-01-05 至 2026-10-15。五份周期模板仍在 `Template` 中，之后的新日记与计划继续按模板创建。本地 Git 历史与远程连接已移除。

## 写什么

各栏用途详见[日记与计划说明](日记与计划说明.md)。模板只保留栏目、勾选项及必要联动；解释、提示语和注释不写入模板。下表用于之后新建的记录，历史笔记不强制套用这些栏目。

| 内容 | 用途 |
| --- | --- |
| 总体目标 | 长期方向及原因，暂不推进的想法 |
| 年 | 选择今年重点，回望重要经历、重视的事情和来年方向 |
| 季 | 选择三个月的重点，根据实际尝试判断哪些方向继续、调整或放下 |
| 月 | 安排本月重点，检查时间与精力投入，决定下个月的取舍 |
| 周 | 接续月重点和上周安排，检查尝试效果，留下下一步 |
| 日 | 习惯、任务、善意与美好、禅、改进、随笔 |

新记录不打分，不要求每日收获或摘要，栏目允许留空。习惯只勾选，可在 `Template/日记模版.md` 中增减。旧笔记原有的字段和栏目按原文保留。

图片、文件和绘图统一自动存入 `Attachment`，不再分子目录，无需手动分类。

“善意与美好”留意收到的支持、给出的善意和普通生活中还不错的片刻，不要求有成果，也不必凑满三条。

“禅”从一件具体事情观察念头、动机与情绪，问自己在期待什么、在意什么，并区分事实与自己的解释。身体与休息、安全与确定、归属与连接、尊重与认可、成长与实现可以作为理解需要的参考，不必强行归类或给需要排高低。

“改进”有具体发现再写；遇到失误时，可以先想想会怎样理解遇到同样事情的朋友，再决定下次怎样做。随笔放在最后，自由记录。用途说明保存在独立说明页中。

## 文件夹规则

创建记录后，目录形如：

~~~text
MOC.md
README.md
总体目标.md
02. Decisions/
  README.md
03. Manual/
  README.md
Template/
Attachment/
01. Daily/
  README.md
  2027年/
    年度计划.md
    第1季度/
      季度计划.md
      01月/
        月度计划.md
        2027-W01/
          周计划.md
          2027-01-04.md
~~~

- 日记按实际日期归入自然年、自然季度和月份。
- 周一到周日为一周；周计划只在周一所属月份存一份，跨月、跨季或跨年均不重复。
- 跨年的日记进入新一年，但链接到同一份周计划。例如 2027-01-01 日记属于 2027 年第一季度，该周周计划属于 2026 年 12 月的 2026-W53。

## 日记目录与自动联动

`01. Daily` 是统一的日记目录，`01. Daily/README.md` 是入口；其中提供最近日记和按年浏览。历史记录已经放入对应年份，之后的新年份会在记录时生成。

新计划中，今年重点显示在季度，本季重点显示在月份，本月重点显示在周计划，本周重点显示在日记。只写一次，不必逐层抄写。对应周期已有旧计划时，日历直接打开旧文件，新记录引用旧计划原有的目标标题；旧文件本身不插入新模板。

周计划提供上一周、下一周的入口，承接月重点和上一周尚在推进的事情，根据实际尝试决定接下来怎样做。日记负责当天的行为与感受，周回看负责检查前次调整和比较多天的经历。周计划不重复拼接每日正文，也不额外列出日记入口；不要求重抄任务或逐条复盘。没有新发现的部分可以留空。

月、季、年逐步拉长观察范围，不把下层记录再汇总一遍。月看安排是否合适，季看方向是否值得继续，年看重要变化和长期选择。上层只保留下一层计划入口。下一阶段可以接续原来的安排，不要求每次提出新目标；若判断改变，应同步修改对应的上层重点。

保留模板中用于引用的标题。日记正文可以自由写，正文内的小标题建议使用二级标题。

## 旧记录的整理方式

- 两处源库共 214 份原始笔记，55 份完全重复的副本合并，旧入口和旧日记模板仅保留原件备份；最终放入 157 份完整旧文件。
- 旧笔记不套模板、不增加六块栏目，也不拆分原来的周记和合并月记。保留原有标题、正文、代码与排版，不补写历史经历、情绪或计划。其中有 105 篇按日记录，另保留两份内容不同的早期版本。
- 年、季、月、周计划按实际周期归位，通常保留原文件名。日历通过隐藏索引定位旧文件，首页兼容没有类型属性的旧日记，并提供合并记录和其他版本的入口。
- 只调整搬移所需的内部链接。一个原有文档引用 `02_DOMAIN_OBJECT_CONTRACTS` 未在两处源库中找到目标，保留原文并记入清单。
- 月份按实际日期纠正旧目录中的错位。原计划有 6—8 月、9—10 月、11 月至次年 1 月等自定义范围，以“阶段计划（原范围）”命名，放在起始月份所属自然季度，正文完整保留。寒假计划根据年末跨年上下文归入 2026 年 1 月，依据记录在隐藏清单中。`2026-3.md` 整份放入 2026 年 3 月，不为其中未注明日期的段落猜测日期。
- 没有 2024 年日记，之前自动生成的空白上级计划已移除。旧笔记中的 2024—2025 学习规划仍按原文保留。
- 原来的长期待办完整保留为根目录 `长期待办任务.md`；已经修改过的 `总体目标.md` 保持原样。
- 两处源目录均未修改。原始文件逐字副本位于隐藏的 `.local/日记整理/原始文件`；恢复前的整理版本和恢复清单位于 `.local/旧笔记原样恢复`，日常使用无需管理。

## 插件与维护

保留并适配日历、Templater、Dataview、首页、心情球、看板、绘图、图片、标签和主题等插件。日常创建交给本地“轻量 OKR 联动”，Templater 保留手动插入功能，避免重复自动插入。

命名与外观参考原库：`01. Daily`、`Template`、`Attachment`、`MOC.md`，以及 Blue Topaz 主题、字体和配套样式。MOC 是热力图主页，README 是仓库说明。首页记录日历只统计日记，不评分；journal-home 样式只作用于主页。Minimal 专用设置插件保留为可选项，默认关闭，避免与 Blue Topaz 配置冲突。

左侧导航使用低饱和度配色：Daily 青色、Decisions 蓝色、Manual 紫色，附件灰色、模板暖灰色。图标插件与主题图标一起适配，样式位于 `.obsidian/snippets/workspace-navigation.css`，外观设置中已启用。

日历、首页、核心日记与剪藏入口直接使用对应日期的文件夹，没有中转目录。新记录首次创建时套用模板；已有旧记录则直接打开，不重新套模板，也不为打开旧文件额外生成空白上级计划。剪藏继续写入当天文件。

开发文件放在隐藏的 .dev 目录。插件适配详情见 [插件适配.md](插件适配.md)；安装 Node.js 后可在仓库根目录运行：

~~~sh
node .dev/验证.cjs
node .dev/验证板块.cjs
~~~

验证使用内存仓库，不生成实际日记。插件升级后应重跑，尤其检查日历路径接口与心情球兼容补丁。自动检查不替代 Obsidian 界面的交互验证。

日记只在本地整理和使用，没有 Git 远程连接。历史内容核对可运行 `node .dev/核对日记整理.cjs`。
