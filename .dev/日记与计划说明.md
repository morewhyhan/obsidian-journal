# 日记与计划说明

[仓库说明](../README.md) · [主页](../MOC.md)

这里解释各栏用途，不会插入新建的日记或计划。栏目可以留空。

## 日记

| 栏目 | 用途 |
| --- | --- |
| 习惯 | 勾选当天的习惯。习惯项目可在日记模板中自行增减。 |
| 任务 | 写今天准备做的事，承接本周重点，也容纳临时事项。 |
| 善意与美好 | 记录收到的支持、给出的善意，以及生活中还不错的小片刻。 |
| 禅 | 观察具体事情中的念头、动机和情绪：我在期望什么？哪些是事实，哪些是自己的解释？ |
| 改进 | 有具体发现时，记下下次可以换的做法；也可以想想会怎样理解遇到同样失误的朋友。 |
| 随笔 | 自由记录经历、想法和感受。 |

## 周计划

| 栏目 | 用途 |
| --- | --- |
| 本周重点 | 从本月重点和上周安排中，选出本周接着推进的事情；这一节会显示在日记中。 |
| 本周重点推进到哪了？ | 留下目前的位置、进展和卡点，方便下周接续。 |
| 什么做法有效，什么问题反复出现？ | 对照几天的经历，判断哪些做法保留、哪些需要调整。 |
| 下周接着做什么，准备怎么做？ | 留下下一步从哪里开始，以及继续、调整或暂停什么。 |

## 月计划

| 栏目 | 用途 |
| --- | --- |
| 本月重点 | 从本季重点中选择本月准备推进的事情。 |
| 本月重点推进到哪了？ | 记录阶段位置和重要变化。 |
| 时间和精力花得合适吗？ | 回看投入、休息和安排是否合适。 |
| 下个月优先做什么，减少什么？ | 对照本季重点，决定下一阶段的取舍。 |
| 本月的周 | 自动提供周计划入口。 |

## 季计划

| 栏目 | 用途 |
| --- | --- |
| 本季重点 | 从今年重点中选择这三个月集中投入的事情。 |
| 本季重点推进到哪了？ | 记录阶段位置，以及影响后续的进展或障碍。 |
| 哪些方向值得继续，哪些需要调整？ | 根据实际经历，重新判断目标、做法和现实条件。 |
| 下季度集中做什么？ | 决定接续、改变或放下哪些事情。 |
| 三个月 | 自动提供月计划入口。 |

## 年计划

| 栏目 | 用途 |
| --- | --- |
| 今年重点 | 从总体目标中选择今年愿意投入的方向。 |
| 这一年有哪些重要经历和变化？ | 回望重要经历、关系、选择，以及今年重点的位置。 |
| 现在更重视什么，哪些目标可以放下？ | 重新认识自己的取舍，需要时更新总体目标。 |
| 明年想把时间留给什么？ | 确定来年愿意投入的方向，也给休息和未确定的事情留空间。 |
| 四个季度 | 自动提供季度计划入口。 |
