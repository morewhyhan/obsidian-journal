# 插件适配

内置插件的配置与兼容说明。使用原库的 Blue Topaz 主题与配套外观设置；历史日记放在 01. Daily，插件配置不带账户数据。

| 插件 | 适配 |
| --- | --- |
| light-okr | main.js 为自包含打包入口，只从宿主引用 Obsidian API；源码为 core/dashboard/plugin.js，修改后运行 `node .dev/构建联动插件.cjs`。保留主页导航、Daily 周期联动与旧记录定位；加载后刷新已打开的 Dataview 页面。Decisions、Manual 为普通目录，不自动创建或套用内容模板。 |
| obsidian-super-mindmap | 插件目录已与 manifest id 统一，保留视图和样式，清空试用标识。 |
| callout-manager | 保留提示块显示。 |
| cmdr | 保留导图命令，指向 manifest id 对应插件。 |
| colored-tags-wrangler | 保留原有标签颜色；不依赖目录。 |
| contribution-graph | 根目录 MOC 主页保留日记热力图，按日记篇数自动展示，不使用评分。窄窗口可横向滚动。 |
| dataview | 已启用 JavaScript，首页兼容没有 type 属性的旧日记和旧年度笔记，按日期跨文件夹查询。 |
| dust-calendar | 年月季使用自然日历路径；已有旧周期记录时按隐藏索引打开原文件，周入口按周一定位，关闭重复模板插入。 |
| homepage | 启动以阅读模式打开根目录 MOC.md；主页提供今天、当前计划、三个板块与最近日记。README 负责仓库说明，各板块保留 README 入口。 |
| memory-orbs | 日期文件名不变，根目录扫描已适配自然年目录；1.0.3 本地兼容补丁，更新后需重新验证。 |
| mousewheel-image-zoom | 保留，不依赖目录。 |
| obsidian-basetag | 保留标签显示；不依赖目录。 |
| obsidian-excalidraw-plugin | 绘图统一存入 Attachment，不预设脚本、字体或绘图模板目录。 |
| obsidian-image-toolkit | 保留，附件目录统一为 Attachment。 |
| obsidian-style-settings | 沿用最初参考库的 Blue Topaz 配色和标签样式。 |
| oz-clear-unused-images | 使用回收站并排除模板，适配附件目录。 |
| recent-files-obsidian | 历史清空，新库自然记录。 |
| supercharged-links-obsidian | 保留标签选择器与配套样式，不依赖旧日期目录。 |
| tag-summary-plugin | 保留；现有摘要不依赖标签手工补录，可自行使用正文标签汇总。 |
| templater-obsidian | Template 只保留年、季、月、周、日五份周期模板；Daily 新建由联动插件完成，手动插入仍可用，避免重复自动插入。 |
| terminal | 保留命令，不设置自动运行。 |
| obsidian-clipper | 使用核心日记的完整日期路径，直接写入当天随笔；无中转目录。 |
| obsidian-icon-folder | 三板块使用日历、指南针、书本图标，分别配青、蓝、紫色；模板和附件采用中性色。workspace-navigation 样式同步覆盖主题图标颜色并避免重复图标。 |
| obsidian-kanban | 保留 Markdown 看板能力，无旧路径；不额外生成必填看板。 |
| obsidian-minimal-settings | 保留安装，默认关闭；仅切换到 Minimal 主题时启用。 |

插件升级后，使用隐藏的 .dev 目录中的验证脚本复查路径、日历接口和心情球补丁；`node .dev/验证加载.cjs` 专门检查单文件加载与插件缺失时的页面显示。不要将不同模板系统同时设为自动插入。
