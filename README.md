把年、季、月、周的计划接到每天，在同一个笔记库里安排时间、记录行动、想清选择、积累方法。

打开主页，就能进入今天的日记和当前周期计划；写过日记的日子会在热力图上点亮。目录、模板和常用入口已经配好，你从第一篇日记开始写。

[打开主页](MOC.md) · [浏览日记](<01. Daily/README.md>) · [了解可选 AI 助理](.agent/Research/README.md)

## 它具体帮你省下什么

| 日常需要 | 模板提供的东西 | 你得到的结果 |
| --- | --- | --- |
| 把大计划落实到今天 | 年→季→月→周→日逐层引用本级重点 | 打开日记时，可以沿着链接找到这件事对应的计划 |
| 每天有地方写 | 统一模板、日期目录和新建入口 | 选日期就能进入记录，已有正文保留 |
| 看见自己的连续记录 | 主页日历、最近日记和热力图 | 想回看某一天时，有明确入口 |
| 分清做事、判断和方法 | Daily、Decisions、Manual三个平级目录 | 行动有记录，重要选择有过程，可复用的方法找得到 |
| 保持写日记的负担小 | 日记只留填写项，说明放在文档里 | 写习惯、任务、感受和随笔，免去每次删除说明文字 |

例如，你想提升英语：在年计划确定方向，在月、周计划缩小到眼前重点，再在日记里记录今天的练习。遇到“该换哪种学习方法”的问题，写进Decisions；找到有效练习步骤后，留在Manual，下次直接使用。

这里的层级引用帮助你接续计划，具体取舍由你写。模板不会因为上层有目标，就自行生成一整年的任务。

## 从第一天开始

1. 用Obsidian打开这个文件夹，启用随库配置的第三方插件。主页依赖轻量OKR联动、Dataview和热力图插件；模板联动使用Templater。
2. 打开 [主页](MOC.md)，进入今天；Alt+D打开今天，Alt+W打开本周。缺失周期笔记按模板创建。
3. 在日记里直接写。Decisions和Manual自由新建笔记，按自己的实践组织内容。

Daily中的`YYYY年`是空白目录展示样例，每周展示多篇日记的位置；实际使用按日期生成。历史笔记可以保留原样，开始使用不需要批量改写旧内容。

## 想让计划有人接着跟进？

可选的QQ助理让你在聊天里交代任务、确定安排、接收到期提示，再把进展接回同一份笔记。比如：

> 明天十点到十一点写报告，先列三个要点，下午六点截止。验收是第一节写完并检查。

它把这句话转成可追踪事项、执行时段和日记记录。你后来告诉它“还需要半小时”或“资料没齐”，它会检查受影响的安排；涉及重要取舍时带建议来问。

笔记模板可独立使用。QQ助理需要单独部署服务、配置模型和账号，并完成机器人登录。

- [助理介绍](.agent/Research/README.md)：能解决哪些具体问题，怎样使用。
- [PRD](.agent/Research/PRD.md)：功能、流程、边界和验收标准。
- [架构图册](.agent/Research/Architecture-Atlas.md)：总览与八个视角，直观看设计怎样工作。
- [工程架构](.agent/Research/ARCHITECTURE.md)：实施基线与目标要求。
- [DDD](.agent/Research/DDD.md)：当前实现、已取得证据与部署维护；不把目标设计当作已实现。
