# 个人工作台模板

[打开主页](MOC.md) · 热力图、今天的日记和当前计划都在主页。

这个仓库用三个平级目录，分别处理**执行、判断和方法**。根据眼下需要，进入对应目录即可。

| 目录与入口 | 用来做什么 | 什么时候用 |
| --- | --- | --- |
| [01. Daily · 日记与计划](<01. Daily/README.md>) | 安排时间，记录日常行动、经历和感受，回看并调整生活 | 今天怎么安排、发生了什么、接下来怎么做 |
| [02. Decisions · 问题研究](<02. Decisions/README.md>) | 围绕实际问题整理情况、想清原因和解决办法，帮助确定方向和作出选择 | 有个问题需要弄清楚，或者有个重要选择拿不定 |
| [03. Manual · 技能手册](<03. Manual/README.md>) | 保存下次能直接使用的方法、步骤和检查清单，减少重复摸索 | 同类事情以前做过，想找现成办法 |

三个目录平级，可以互相链接，也可以独立使用。不需要把每篇日记都整理成研究或技能。

## 其他目录和文件

| 名称 | 用途 |
| --- | --- |
| [Someday](Someday.md) | A quiet place for ideas and possibilities to revisit later. Nothing here is a commitment. |
| Template | 新建笔记时使用的模板 |
| Attachment | 图片、文件等附件统一存放处 |

## 怎么开始？

- 写日记：进入 Daily，点击“今天”或选择日历日期。Alt+D 打开今天，Alt+W 打开本周。
- 研究问题：在 Decisions 目录中自行新建笔记。
- 保存技能：在 Manual 目录中自行新建笔记。

`MOC.md` 是主页，Obsidian 启动时自动打开；MOC 是 Map of Content 的缩写，通常指内容导航页。本仓库用它承载热力图与常用入口。

每个目录中的 `README.md` 是该目录的说明和入口。若从旧库复制笔记，保留原样；日记与计划沿用模板，Decisions 和 Manual 的内容及组织方式由自己决定。
