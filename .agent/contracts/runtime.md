# 调度和运行入口

权威规则见[主规格](../SPEC.md)：第 6 节调度、第 8 节保存与恢复、第 9 节运行数据库、第 10—12 节适配与接口。

Core 单实例写入，内部每 30 秒 tick。AstrBot 可自主调用 workspace 操作笔记，业务状态仍提交提案；调度不依赖模型常驻思考。SQLite 必须启用，保存五类最小运行记录；长期事实仍保存在文件中。NapCat 与 AstrBot 通过内部反向 WebSocket 连接，Core 只接收已绑定账号的输入并负责投递。

文件与 SQLite 没有跨介质原子事务，必须按主规格实现 prepared 操作与幂等恢复。未知投递不盲目重试，过时提醒不积压补发。
