# 保存、备份与恢复入口

完整规则见[主规格第 8 节](../SPEC.md#8-文件保存并发和故障恢复)和[第 13 节](../SPEC.md#13-git-自动备份与恢复)。

只有服务器工作树与私有 GitHub 备份；Web 和 QQ 经过同一个 Core，不增加 Windows 本地 Git 副本。正文写 Markdown，SQLite 只存运行记录。浏览器草稿在本机暂存，不建数据库 draft 表。

生产私有数据仓库必须调整模板原有忽略规则，否则年份日记、附件和秘书长期文件会漏备份。数据库、密钥和日志不进 Git。远端冲突停止推送，不强推，不自动覆盖。

数据库丢失不保证恢复尚未处理输入或已发消息回执，按主规格进入保守重建，不把它描述为无损缓存恢复。
