# 秘书与日记的关联入口

完整规则见[主规格第 3 节](../SPEC.md#3-目录真源和持久数据)和第 7.4 节。

秘书的定义、安排和发生记录在 `.agent/state/`；用户的叙述正文在原 Markdown。秘书可工作在日记未创建时；未来创建后按当前事实补投影。

只自动修改已绑定的 `# 习惯`或`# 任务`复选框，以及用户已接受的新行。绑定在 registry，不向日记塞机器 ID 或解释文字。禅、随笔、改进、善意与美好默认不读不写；用户本次明确请求分析时才读取授权片段。

手工勾选是新输入，空框不是失败；删除展示行不取消承诺。写入只改必要字符，正文其他字节保留。
