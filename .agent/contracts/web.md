# Web 和笔记入口

完整规则见[主规格第 7 节](../SPEC.md#7-web日记目录和兼容)、第 8 节保存和第 12 节 API。

响应式 Web 提供原生主页、年季月周日导航、Markdown 编辑、事项和搜索。三个板块同排随窄屏自然换行，图标分色。说明放帮助中，不写进模板正文。

沿用自然季度；跨年周按自然年分别创建。旧笔记不迁移或套模板。Web 不执行 Obsidian 插件、Templater 或 DataviewJS，以受控渲染和查询提供相应基础能力。

正文只在文件中保存；SQLite 无正文或草稿表。所有保存带 base_hash，有冲突时保留两方内容。
