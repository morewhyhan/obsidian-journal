# 短期运行数据

此目录由 Core 管理，不出现在普通笔记树，不进入私有 Git 备份。真实服务尚未创建数据库。

运行后创建 `state.sqlite`，只包含 schema_meta、documents、inbox、events、outbox 五张表，结构见[SQL 契约](../contracts/schema.sql)。正文、草稿、提示词和知识库不复制进来。

长期业务记录保存在 `../state/`，不随运行事件清理而删除。数据库清理期限、文件压缩、未完成状态处理和丢库降级见[主规格第 9 节](../SPEC.md#9-最小-sqlite-和清理)。

删除正文后的运行记录不等于文件立即缩小；清理和空间回收分开执行。不得删除活跃 WAL/SHM，不能以缩小体积为由丢掉尚未完成的操作。
