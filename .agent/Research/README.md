# 私人 AI 助理

**在QQ里交代事情，后续有人准确接着办。**

它面向一个人的日常使用：接住任务、查找已有资料、安排时间、按约定提醒、记录进展，在计划变化后继续处理。笔记正文保存在自己的Markdown文件里。

例如，你确定了明天的四件事，随后说“语法改到下午，其他照旧”。我们要交付的效果是：四件事都被接住，只改指定部分，日记和提醒跟着更新。你说任务遇到问题时，助理先查已有背景，能处理的处理，需要取舍时带建议来问。

## 使用范围

- QQ是当前MVP的协作入口；NapCat负责QQ连接，AstrBot与项目插件接入模型和受控工具。
- 习惯记录约定行为是否发生；任务按明确成果验收。
- 提醒时间、联系范围和个人规则可以调整；不以沉默判失败，不要求每日主观评分。
- 日记与计划通过现有模板联动，保留人工正文；Obsidian模板可独立使用。

这些是产品目标。已有代码和部分测试不代表全部体验已经达标；当前新架构仍待逐步实施。

## 启动入口

服务工程位于仓库的 .dev/secretary-service，使用package.json约定的Node版本。在服务目录运行npm ci、npm run contracts、npm run check和npm test；构建使用npm run build。

容器配置在deploy/compose.yaml，变量示例在deploy/deployment.env.example与deploy/secret.env.example。实际秘密放仓库外，笔记数据使用独立目录。配置好环境后启动core、astrbot、napcat，完成NapCat扫码；真实使用前先核本人身份、文件操作和一条指定消息。命令与配置需按实际环境检查，不能把设计目标当成生产已具备的能力。
